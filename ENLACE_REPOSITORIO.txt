Proyecto:
MaquinaAutoservicioGestionEnvios

Descripción:
Módulo web para la gestión de envíos desarrollado mediante Java,
Servlets, JSP, JDBC, Maven y MySQL.

Funcionalidades:
- Registro de envíos.
- Consulta de envíos.
- Búsqueda de envíos por ID.
- Actualización de envíos.
- Eliminación de envíos.
- Conexión con base de datos MySQL.
- Implementación del CRUD mediante JDBC.
